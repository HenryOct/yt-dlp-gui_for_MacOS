# yt-dlp GUI Downloader (macOS) · yt-dlp 图形界面下载器

🍎 A native SwiftUI graphical downloader for yt-dlp on macOS.
本项目是 macOS 上的 yt-dlp 图形界面下载器，原生 SwiftUI 实现。

## ✨ Key Features · 核心特性

- **🌐 Powerful downloads · 强大下载**：Supports 1000+ sites including YouTube, Bilibili / 支持 1000+ 网站，包括 YouTube、Bilibili
- **📃 Playlist-aware · 播放列表支持**：Downloads full playlists and tracks overall playlist progress, not just the current video / 支持整个播放列表下载，显示播放列表整体进度而非仅当前视频
- **🎯 Smart formats · 智能格式**：Preset quality options plus custom format strings, with a format-check tool / 预设质量选项 + 自定义格式字符串，内置格式检查工具
- **🌐 Proxy support · 代理支持**：HTTP / HTTPS / SOCKS5 / 支持 HTTP / HTTPS / SOCKS5 代理
- **🍪 Browser cookies · 浏览器 Cookies**：Import from Chrome/Firefox/Safari/Edge for login-gated or premium content / 从 Chrome/Firefox/Safari/Edge 导入 Cookies，支持登录态和会员内容
- **🔄 Auto-managed dependencies · 自动管理依赖**：Detects and installs/updates `yt-dlp[default]` via `pip`, plus a JavaScript runtime (Deno or Node.js) needed for solving site JS challenges — all set up automatically on first launch, with results shown directly in the UI / 自动通过 `pip` 安装/更新 `yt-dlp[default]`，并自动安装解决网站 JS 验证所需的 JavaScript 运行时（Deno 或 Node.js）——首次启动时自动完成，结果直接显示在界面上
