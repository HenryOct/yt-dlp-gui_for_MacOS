# yt-dlp GUI Downloader (macOS) · yt-dlp 图形界面下载器

🍎 A graphical downloader for yt-dlp on macOS, available in two parallel GUI implementations — a wxPython (Python) version and a SwiftUI (native) version — sharing the same features and calling the same pip-managed `yt-dlp`.
本项目是 macOS 上的 yt-dlp 图形界面下载器，提供两套并存的 GUI 实现——wxPython（Python）版本和 SwiftUI（原生）版本，功能对等，底层都通过 pip 管理并调用 `yt-dlp`。

## ✨ Key Features · 核心特性

- **🌐 Powerful downloads · 强大下载**：Supports 1000+ sites including YouTube, Bilibili / 支持 1000+ 网站，包括 YouTube、Bilibili
- **📃 Playlist-aware · 播放列表支持**：Downloads full playlists; the SwiftUI version tracks overall playlist progress, not just the current video / 支持整个播放列表下载，SwiftUI 版会显示播放列表整体进度而非仅当前视频
- **🎯 Smart formats · 智能格式**：Preset quality options plus custom format strings, with a format-check tool / 预设质量选项 + 自定义格式字符串，内置格式检查工具
- **🌐 Proxy support · 代理支持**：HTTP / HTTPS / SOCKS5 / 支持 HTTP / HTTPS / SOCKS5 代理
- **🍪 Browser cookies · 浏览器 Cookies**：Import from Chrome/Firefox/Safari/Edge for login-gated or premium content / 从 Chrome/Firefox/Safari/Edge 导入 Cookies，支持登录态和会员内容
- **🔄 Auto-managed yt-dlp · 自动管理**：Detects and installs/updates yt-dlp via `pip` automatically, with the result shown directly in the UI / 自动检测并通过 `pip` 安装/更新 yt-dlp，结果直接显示在界面上

`macos-swift/build/` (Xcode build output) and each version's local Python `venv/` are git-ignored and not part of the repo.
`macos-swift/build/`（Xcode 构建产物）和各版本本地的 Python `venv/` 已加入 `.gitignore`，不纳入版本管理。

**Two versions, one feature set · 两个版本，功能对等**：`macos-swift/` is a SwiftUI reimplementation of `core/yt_dlp_gui_wx.py`'s GUI — same tabs (Basic Settings / Advanced Settings / Log), same options, same command-line arguments passed to yt-dlp. Neither directory depends on the other; pick either one to run. See [core/README.md](core/README.md) and [macos-swift/README.md](macos-swift/README.md) for build/run instructions and troubleshooting.
`macos-swift/` 是对 `core/yt_dlp_gui_wx.py` 界面的 SwiftUI 重写——同样的三个 Tab（基础设置/高级设置/日志）、同样的选项、拼给 yt-dlp 的命令行参数也一致。两个目录相互独立，运行任意一个即可。构建/运行说明和故障排查请见 [core/README.md](core/README.md) 和 [macos-swift/README.md](macos-swift/README.md)。
